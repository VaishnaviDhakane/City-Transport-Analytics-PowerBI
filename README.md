## 📌 Project Overview  
The City Transport Analytics Dashboard is an end-to-end data analytics project developed using Power BI to analyze and visualize urban transportation data. The primary goal of this project is to understand passenger travel patterns, identify peak travel hours, and evaluate route-wise performance to support efficient decision-making in city transport management.

This project converts raw transport data into meaningful and actionable insights through proper data cleaning, modeling, and interactive visualizations. The dashboard enables users to explore data dynamically and gain a clear understanding of transport system performance.


## 🛠 Tools & Technologies Used  

- Power BI  
  - Data modeling and relationship management  
  - Interactive dashboards and visual reports  
  - KPIs, charts, tables, and slicers for analysis  

- Microsoft Excel  
  - Data cleaning and preprocessing  
  - Handling missing values and inconsistencies  
  - Structuring raw data for Power BI analysis  


## 📊 Key Insights & Analysis  

- Passenger Trends by Route  
  Identifies high-traffic and low-traffic routes based on passenger volume, helping in demand analysis.

- Peak Hours Analysis  
  Highlights peak and off-peak travel hours to support better scheduling and resource planning.

- Route-wise Performance Comparison  
  Evaluates the performance of different routes to understand operational efficiency.

These insights help stakeholders make data-driven decisions to improve service quality and optimize city transport operations.
